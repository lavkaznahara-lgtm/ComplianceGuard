# Security Policy

## Supported Versions

Currently, only the latest `main` branch and the `v1.0.0` release are supported with security updates.

## Reporting a Vulnerability

If you discover a vulnerability in ComplianceGuard, please **do not** open a public issue. 

Instead, please send an email to lavkaznahara@gmail.com. I will try to respond within 48 hours and will keep you updated on the fix.
